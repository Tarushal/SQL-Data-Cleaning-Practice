# SQL-Data-Cleaning-Practice
SQL Data Cleaning Practice Project - using a layoffs dataset, completed while following Alex The Analyst's tutorial

## Project Overview
This project demonstrates common SQL data cleaning techniques using a layoffs dataset in MySQL.

This project was recreated while following Alex the Analyst's SQL Data Cleaning Portfolio Project as part of my SQL learning  journey. My objective was to understand the reasoning behind each data cleaning step and strengthen my practical SQL skills.

## Objectives
* Create a Staging table to preserve the original dataset
* Identify and remove duplicate records
* Standardize inconsistent values
* Handle NULL and blank values
* remove unnecessary columns after cleaning

## Skills Practiced
* Data cleaning
* Data transformation
* Common Table Expressions (CTEs)
* Window functions (ROW_NUMBER())
* String functions (TRIM)
* Date formatting
* UPDATE statements
* ALTER TABLE
* DELETE statements

## Tools Used
* MySQL
* MySQL Workbench

## Dataset
Layoffs dataset used in Alex the Analyst's SQL Portfolio Project.
